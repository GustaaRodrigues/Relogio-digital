# ⏱️ Relógio digital
<br>
Esse projeto é meu primeiro projeto pessoal da faculdade da matéria de Web coding. Orientado pela professora Noemi Honorato.<br>
<br>
Um relógio digital desenvolvido com HTML, CSS e JavaScript.

# 💻 Linguagens utilizadas
<br>

* __HTML:__ Cria a estrutura básica da página, organizando os espaços onde o horário e a data são exibidos.

* __CSS:__ Faz a interface com um visual futurista usando a fonte Orbitron e um fundo em gradiente.

* __JavaScript:__ Pega a data e hora do sistema, formata os números para sempre exibir dois dígitos e atualiza a tela a cada 1 segundo.
