Esse projeto é meu primeiro projeto pessoal da faculdade da matéria de Web coding. Um relógio digital em tempo real desenvolvido com HTML, CSS e JavaScript.

HTML: Cria a estrutura básica da página, organizando os espaços onde o horário e a data são exibidos.

CSS: Faz a interface com um visual futurista usando a fonte Orbitron e um fundo em gradiente pra ficar bem bonito.

JavaScript: Pega a data e hora do sistema, formata os números para sempre exibir dois dígitos e atualiza a tela a cada 1 segundo.
